## Скрипт для очистки баз данных Аккорда серии GXM2.

**Кратко:**

Скрипт очищает БД пользователей, БД контроля целостности и Журнал в Аккорде серии GXM2. Запускать из-под sudo.

**Синтаксис:**

`sudo ./acle-gxm2-erase-db.sh [options]`

**Флаги:**
* `-f` - принудительно очищать аккорд, даже если в ЭВМ вставлено несколько устройств(требуется подтверждение). Возможно неопределенное поведение.
* `--force-local-utils` - принудительно использовать утилиты только из проекта

**Развернутное описание:**

Скрипт ищет утилиту acle-write-sectors через whereis (т.е. в стандартных директориях PATH), в случае, если не находит, то использует утилиту из директории accord-le/tools/acle-write-sectors (автоматически собирает утилиту с помощью make, если пользователь этого не сделал). С помощью *--force-local-utils* можно изменить поведение: скрипт будет запускать утилиту только из проекта, а не из установленных.

Скрипт проверяет, является ли версия установленного Аккорда поддерживаемой данным скриптом.

В случае, если в ЭВМ установлено более одного Аккорда, утилита завершит свою работу. Изменить данное поведение можно с помощью флага *-f*, будет выведено, с каким аккордом будет произведено действие и запрошено подтверждение.

Скрипт всегда завершает свою работу, не совершая никаких действий, если в ЭВМ присутствует модель не из списка:

* Аккорд-GX5 (M.2) - GX5AE, DeviceID - 0x0735

*расположение скрипта: accord-le/tools/scripts*
