### Соглашение о наименованиях ###
Общее название такого рода девайсов - Accord-LE. 


### Внутренние названия ###
старый LE (PCI-Express) - LE, DeviceID - 0x700, на плате над разъемом PCIe присутствует м/cx TI XIO2001.
новый LE (PCI-Eхpress) - GX, DeviceID - 0x710
новый LE (mini PCI-E full size) - GXМ, DeviceID - 0x715
новый LE (mini PCI-E half size) - GXМН, DeviceID - 0x720


### Мануал по созданию образа прошивки для Аккорд АМДЗ ###
Все операции следует проводить с правами администратора!

Шаг 1. Создание образа системы initrd
	1. Распаковываем образ:
		# mv initrd initrd.cpio.lzma
		# lzma -d initrd.cpio.lzma
		# mkdir rootfs
		# cd rootfs
		# cat ../initrd.cpio | cpio -id
После этого, в каталоге rootfs появится корневая ФС образа.
	2. Заменяем необходимые файлы (amdz-ng-gui, библиотеки в lib и т.д.) на новые (при необходимости сделать strip файлов для уменьшения их размера)
	3. Запаковываем образ.
		# cd rootfs
		# find . | cpio -H newc -o > ../initrd
		# lzma initrd

Шаг 2. Создание образа прошивки image.bin
За создание файла прошивки отвечает набор скриптов находящихся в проекте amdz-ng.
	1. Скачать и распаковать исходники загрузчика grub.
		# ./00-get-grub
	2. Наложить на исходники grub патчи, содержащие код драйверов для загрузки ОС с контроллеров Аккорд-5.5+ и Аккорд-LE
		# ./01-patch-grub
	3. Собрать grub
		 #./02-build-grub
	4. Создать загрузочный образ grub. Список команд, выполняемых после инициализации grub находится в файле boot-sequence.
		# ./03-grub-mkfloppy
	5. Скопировать в каталог "data" ядро и initrd в файлы "linux" и "initrd" cоответственно.
		# cp /path/to/bzImage ./data/linux
		# cp /path/to/initrd.cpio.lzma ./data/initrd
	6. Создать образ ФС с файлами ОС.
		# sudo ./04-make-os-image os-image
	7. Создать загружаемый образ	
		# ./05-make-boot-blob os-image image.bin
Соответсвенно, когда первые 4 операции делаются только один раз, и при создании последующих образов нужно только скопировать необходимые файлы в папку data/ и выполнить пункты 6 и 7.

Шаг 3. Прошивка образа в память Аккорда
Для контроллеров Аккорд-5.5+ это делается из DOS с использованием утилиты ld55disk.exe, входящей в состав компакт-диска "Аккорд-АМДЗ". Для контроллеров Аккорд-LE/GX это делается из linux с использованием утилиты tools/update-os из репозитория accord-le
	# ./update-os image.bin

План показа:
1. Подключение АРМ к серверу СУЦУ (появляется новый АРМ в интерфейсе администрирование на сервере СУЦУ)
2. Краткий экскурс по интерфейсу сервера СУЦУ
3. Проверка функциональных возможностей СУЦУ (отправка запросов клиенту СУЦУ // проверка возвращаемых значений на сервере):
	* просмотр списка пользователей
	* создание нового пользователя АМДЗ
	* просмотр списка пользователей (в список должен добавиться пользователь)
	* удаление созданного пользователя
	* просмотр списка пользователей (список пользователей должен стать прежним)
	* экспорт/импорт СКЦ (на некотором тестовом приложении с демонстрацией вывода ошибки в АМДЗ и невозможности загрузиться обычным пользователем)
	* удаленное обновление прошивки АМДЗ (с 0.3.0.20 на 0.3.0.19 и обратно)
	* просмотр журналов работы АМДЗ (журналы во время показа каждый раз выгружаются по расписанию)
