## Скрипт для создания бинарника с дампом указанной зоны Аккорда

**Кратко:**

Скрипт создает бинарник с дампом указанной зоны Аккорда

**Синтаксис:**

`amdz-gx-dump.sh [flag] <altera|bios|log|user|kc|os|db|inaf_compt> <file.name> <gx|gxm2|auto> <input_db_file_path>`

**Флаги:**

* `-f` - принудительно делать дамп аккорда, даже если в ЭВМ вставлено несколько устройств(требуется подтверждение). Дамп будет сделан с устройства, к которому присоединен драйвер

**Развернутное описание:**

Скрипт используется, чтобы сделать дамп одной или нескольких зон аккорда. Функционирует только с присоединенным драйвером accord-le. Принимает до 4 аргументов и флаг, последние два аргумента и флаг опциональны, остальное обязательно.

* Первый аргумент - указывает на тип базы, который считываем
	altera - альтера
	bios - ROM BIOS
	log - журнал
	user - база пользователей
	kc - база КЦ (полная)
	os - образ OS
	db - (user+log+kc)
	inaf_compt - база в режиме совместимости для ИНАФ. (полный дамп содержимого GX до операционной системы, для GX5 это дамп с отрезанным началом (отрезается кусок альтеры), чтобы база пользователей начиналась с того же смещения, как и GX)
	*Если к параметру добавить + (user+) - то снимается дамп памяти с указанной базы и до конца диска АМДЗ*

* Второй аргумент - файл, куда сохранить.

* Третий аргумент (необязательный) - тип контроллера, с которым работаем. По умолчанию auto
	gx - разметка контроллера серии GX
	gxm2 - разметка контроллера серии GXM2
	auto - автоматическое определение серии контроллера
	
* Четвертый аргумент (необязательный) - путь до файла, который выбирается источником для дампа вместо стандартного пути АМДЗ. Функционирует только в случае, если третьим аргументом указана опция gx или gxm2

*расположение скрипта: accord-le/tools/scripts*
